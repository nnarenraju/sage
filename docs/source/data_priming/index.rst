Downloading Data & Priming Sage
================================

Before training, Sage needs real LIGO strain data on disk in a compact binary format.
This guide walks through the four steps: querying available science segments, cleaning
the timeline, splitting it into fixed-length chunks, and downloading from GWOSC.

Validation and Figures
======================

A trained network is checked on windows it never trained on. These pages
show how Sage validates a run, the figures it draws, and how to compare runs
and benchmark one.

:doc:`during`
   The validation passes during training, and what they store.

:doc:`figures`
   Drawing the validation figures with ``sage plot``.

:doc:`validate`
   Validating one stored checkpoint with ``sage validate``.

:doc:`compare`
   Scoring several runs on the same windows with ``sage compare``.

:doc:`benchmark`
   Benchmarking a network on MLGWSC-1 with ``sage benchmark``.
